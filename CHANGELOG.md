# Changelog

## 1.0.0

- Renamed Window Positioner to Positioni.
- Added a visual editor for drawing, moving, and resizing windows, with pixel and percentage dimensions.
- Added ten starter profiles, an onboarding flow, and support for saving incomplete profiles.
- Added selective profile import from Positioni, Sizer, WindowSizer, FancyZones, DisplayFusion, and supported AutoHotkey v2 bindings.
- Added shortcut conflict feedback during editing and import.
- Added light and dark themes and six interface languages.
- Added an installer alongside the portable edition, plus GitHub release checks for both.
