# Changelog

## 1.1.0

### Added

- Choose a Small, Regular, or Large interface size.
- Positioni remembers your window size between sessions.
- During installation, choose where to create shortcuts, whether Positioni starts in the system tray when you sign in, and whether it opens when installation finishes.

### Changed

- The main window opens centered and uses an updated default size on first launch.
- A more compact header leaves more room for profiles and the editor.
- The profile editor is easier to scan, with shorter field labels.
- Improved scroll shadows.
- The installer follows the Windows theme, and installation and uninstallation dialogs use clearer action labels.

### Fixed

- Profile names and shortcuts now have consistent spacing.
- The profile list stays in place when you save changes.
- Fixed clipped text in installer and uninstaller dialogs.

## 1.0.0

- Renamed Window Positioner to Positioni.
- Added a visual editor for drawing, moving, and resizing windows, with pixel and percentage dimensions.
- Added ten starter profiles, an onboarding flow, and support for saving incomplete profiles.
- Added selective profile import from Positioni, Sizer, WindowSizer, FancyZones, DisplayFusion, and supported AutoHotkey v2 bindings.
- Added shortcut conflict feedback during editing and import.
- Added light and dark themes and six interface languages.
- Added an installer alongside the portable edition, plus GitHub release checks for both.
